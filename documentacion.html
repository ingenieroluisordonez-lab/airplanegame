Arquitectura General

El juego está desarrollado íntegramente en GDScript sobre Godot 4.7.2. No usa modelos 3D externos (ni .glb, ni .fbx): toda la geometría se construye en código con meshes primitivas (BoxMesh, SphereMesh, CylinderMesh) e instancias de MeshInstance3D añadidas como nodos hijo en _ready().

Flujo de juego

world.gd (_ready)
  ├── Spawnea jugador ($Player)
  ├── Spawnea 25 enemigos mixtos
  ├── Spawnea globos, zepelines, barcos
  ├── Conecta señales → HUD
  └── _process: sigue cámara, respawnea

player.gd (_physics_process)
  ├── Lee teclado / joystick
  ├── Aplica vuelo + física
  ├── Dispara balas y misiles
  └── Emite health_changed, score_changed

bullet.gd (Area3D, _physics_process)
  └── body_entered → take_damage()

Patrón take_damage()

Todo objeto destruible implementa este método. La bala y el misil lo llaman automáticamente:

func take_damage(amount: int) -> void:
    health -= amount
    if health <= 0:
        # Crear explosión
        var exp := explosion_scene.instantiate()
        get_tree().root.add_child(exp)
        exp.global_position = global_position
        # Emitir señal para sumar puntos
        destroyed.emit(score_value)
        queue_free()

Sistema de Colisiones

Godot 4 usa capas numéricas (1–32). Este proyecto usa 3 capas:

Capa 1 Jugador — CharacterBody3D del player
Capa 2 Enemigos y objetivos — todos los CharacterBody3D destructibles
Capa 4 Balas — Area3D que detecta capas 1 y 2 (máscara = 3)

En el .tscn (enemigo)

[node name="Enemy" type="CharacterBody3D"]
collision_layer = 2
collision_mask  = 1

En el .tscn (bala)

[node name="Bullet" type="Area3D"]
collision_layer = 4
collision_mask  = 3  ← capas 1 + 2

Interfaz (HUD)

El HUD es un CanvasLayer con 6 clases internas que dibujan con la API _draw():

AttitudeIndicator

Horizonte artificial. Usa algoritmo Sutherland-Hodgman para clipear cielo/tierra al rect del control.

SpeedTape

Cinta de velocidad IAS en km/h con caja de valor actual.

AltitudeTape

Cinta de altitud en metros con variación vertical (▲▼).

ThrottleGauge

Medidor circular de motor (verde → naranja → rojo).

CompassDisplay

Brújula horizontal con rumbos cardinales animados.

RadarDisplay

Radar circular. Muestra enemigos como puntos rojos orientados al jugador.

API pública del HUD

# Llamadas desde world.gd / player.gd
$HUD.update_health(value: int)   # barra de vida (0-100)
$HUD.update_score(value: int)    # puntuación total
$HUD.update_kills(value: int)    # contador destruidos
$HUD.show_game_over()             # pantalla DERRIBADO

Cargar Imágenes y Texturas

Godot 4 importa automáticamente cualquier imagen en res://. Coloca tus archivos PNG/JPG en assets/textures/ y úsalos así:

1. Textura sobre un material (lo más común)

func _build_model() -> void:
    # Cargar imagen como textura
    var tex := load("res://assets/textures/tanque.png") as Texture2D

    var mat := StandardMaterial3D.new()
    mat.albedo_texture = tex      # imagen como color base
    mat.roughness      = 0.85

    var mi := MeshInstance3D.new()
    var bm := BoxMesh.new()
    bm.size = Vector3(5, 5, 5)
    mi.mesh = bm
    mi.set_surface_override_material(0, mat)
    add_child(mi)

2. Imagen como ícono en el HUD (2D)

var img_rect := TextureRect.new()
img_rect.texture  = load("res://assets/ui/icono_objetivo.png") as Texture2D
img_rect.size     = Vector2(48, 48)
img_rect.position = Vector2(20, 20)
add_child(img_rect)

3. Cargar desde disco en tiempo real

# Para imágenes fuera del proyecto (ruta absoluta)
var img := Image.load_from_file("C:/fotos/objetivo.png")
if img:
    var tex := ImageTexture.create_from_image(img)
    mat.albedo_texture = tex

4. Sprite 3D (imagen plana en el mundo 3D)

# Útil para carteles, señales, objetivos 2D en el mundo
var sprite := Sprite3D.new()
sprite.texture  = load("res://assets/textures/diana.png") as Texture2D
sprite.pixel_size = 0.05   # tamaño en unidades del mundo
sprite.billboard = BaseMaterial3D.BILLBOARD_ENABLED  # siempre mira a la cámara
add_child(sprite)
Formatos soportados: PNG, JPG, WebP, BMP, TGA, SVG.
Recomendado: PNG con transparencia para sprites, JPG para texturas grandes.
Tamaño: potencia de 2 (256×256, 512×512, 1024×1024) para mejor rendimiento.

Cómo Crear un Nuevo Objeto Destruible

Ejemplo: agregar un tanque en tierra como objetivo.

Paso 1 — Crear la carpeta y el .gd

# scenes/tank/tank.gd
extends CharacterBody3D

@export var health      : int   = 8
@export var score_value: int   = 300

var explosion_scene := preload("res://scenes/explosion/explosion.tscn")
signal destroyed(score: int)

func _ready() -> void:
    add_to_group("target")   # ← clave: usar "target" para ser detectado
    _build_model()

func take_damage(amount: int) -> void:
    health -= amount
    if health <= 0:
        var exp := explosion_scene.instantiate()
        get_tree().root.add_child(exp)
        exp.global_position = global_position
        destroyed.emit(score_value)
        queue_free()

func _build_model() -> void:
    var mat := StandardMaterial3D.new()
    mat.albedo_color = Color(0.3, 0.35, 0.2)   # verde militar
    mat.roughness    = 0.85
    # O cargar textura:
    # mat.albedo_texture = load("res://assets/textures/camuflaje.png")

    var mi := MeshInstance3D.new()
    var bm := BoxMesh.new()
    bm.size = Vector3(5, 3, 9)
    mi.mesh = bm
    mi.set_surface_override_material(0, mat)
    add_child(mi)

Paso 2 — Crear el .tscn

# scenes/tank/tank.tscn
[gd_scene format=3 uid="uid://tank000001"]

[ext_resource type="Script" path="res://scenes/tank/tank.gd" id="1_tank"]

[sub_resource type="BoxShape3D" id="BoxShape_col"]
size = Vector3(5.0, 3.0, 9.0)

[node name="Tank" type="CharacterBody3D"]
collision_layer = 2
collision_mask  = 1
script = ExtResource("1_tank")

[node name="CollisionShape3D" type="CollisionShape3D" parent="."]
shape = SubResource("BoxShape_col")

Paso 3 — Registrar en world.gd

# Al inicio de world.gd:
var tank_scene := preload("res://scenes/tank/tank.tscn")

# En _ready():
for i in 5:
    _spawn_tank()

# Nueva función:
func _spawn_tank() -> void:
    var t : Node3D = tank_scene.instantiate()
    add_child(t)
    t.global_position = Vector3(
        randf_range(-500, 500), 3.5,
        randf_range(-500, 500))
    t.destroyed.connect(_on_target_destroyed)
⚠ Recuerda siempre add_to_group("target") en _ready() para que las balas del jugador y los misiles puedan detectarlo.

Para crear un nuevo juego

  1. Copia la carpeta aviones_v1/ completa a juego_nuevo/
  2. Abre project.godot con Godot o edita config/name
  3. Modifica las escenas en scenes/world/ como punto de partida
  4. Reutiliza explosion/, bullet/, missile/ — son genéricos
